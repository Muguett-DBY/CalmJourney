# CalmJourney

CalmJourney helps sensory-sensitive commuters find quiet public places and check one-hour pedestrian crowd alerts in Melbourne.

## Features

- Nearby parks, libraries and quiet public spaces with details and walking directions
- One-hour crowd forecasts based on City of Melbourne historical and current pedestrian counts
- Supabase PostgreSQL for refuge data, pedestrian sensors, hourly patterns and model validation results

## Development

```bash
npm install
npm run dev
```

Run checks with `npm test`, `npm run lint` and `npm run build`.

Production: https://calmjourney.custard.top
